# Icons still to draw for MagicDungeon

Your supplied 16×16 originals are in `assets/user_icons/`; `sources.json` records the matching source images. The game currently uses 27 of them for armor, health, the healing flask, iron, boots, book, map, treasure/relic indicators, and the sword, greatblade, axe, shield, light armor, heavy armor, helmet and amulet. The actual dungeon treasure chest and enemy characters remain their existing animated / tileset artwork.

The icons below still use existing prototype assets, shared symbols or text. These are suggestions for a fully consistent original icon set; they are not missing game functionality and you do not have to make every item unique.

## Highest priority: important combat stats

- **Temporary shield:** a glowing barrier that looks different from the armor stat shield.
- **Ember:** a glowing coal, if you would like to replace the existing custom coal with your own version.

## Equipment and supplies

- **Dagger:** short fast weapon, visibly distinct from the sword.
- **Ember blade:** a sword that visibly reads as fire-themed. The existing prototype icon remains in use.
- **Hammer / Stonebreaker:** useful in the UI and for cracked walls.
- **Copper key:** separate from treasure and iron.
- **Iron fragments:** optional; the ingot you supplied already represents iron.

Your second sword is currently used as the greatblade. If you intended it as another regular sword, a visibly larger two-handed blade would make that weapon class clearer.

## Exploration and the Hearth

- Rest-site campfire, fountain, forge, shrine and urn, if you want your own versions for map and interface markers. Some of these are presently drawn or use dungeon tiles rather than individual icons.
- A distinct marker for the Hearth / sanctuary, flame fragment, manuscript / discovery, rescued smith and cartographer. The existing book, gem and other symbols work as temporary stand-ins.
- Armory, elemental chamber, dangerous vault and restful passage markers; existing equipment, element, chest and flask icons currently represent these.
- Sun and Moon candles, rune puzzle and locked / guarded chest badges. These can reuse the same chest, key and elemental shapes with small overlay badges.

## Skills, status and menus

- Skill-specific symbols for Quickdraw, heavy momentum, opening hit, shield break, interrupt, regeneration, lifesteal, enemy armor piercing and evasion. Reuse your sword, heart or shield with a small badge where readable.
- Elemental combinations such as Fire + Frost or Frost + Poison can use two element icons side by side; they do not require one custom image per skill.
- Menu icons for settings, sound / mute, music, pause / resume, help, back, close, selection and locked / unlocked. Many can be simple UI-drawn shapes.
- Any boss-mechanic icons you want to distinguish visually: guard, tidal double strike, necromancer healing, furnace heat and eclipse seal.

## Other artwork in the supplied set

The monsters, gems, food, extra bottles, bows and other equipment have been left unused where the current mechanic has no clear match. Enemy sprites in the game currently have animation frames, while the supplied monster images are individual frames; swapping them would change that animation. The very large sheets are reference images, so the game uses the individual transparent files instead of cutting the screenshots.
