# MagicDungeon 0.8 — Clear actions and contextual help

- Press locked Endless or Vow buttons to see how to unlock them: finish a full 5-floor run on this character. The Trial does not count. Daily Vows explain that Daily rules cannot be changed.
- Equipment pickup now uses a larger window: a prominent item illustration and rarity, readable stat comparisons, and three large icon cards for Equip, Keep and Compare. Existing 1 / 2 / E shortcuts remain available.
- Salvaging is labeled Scrap. The equipment window has Gear help and a separate ? beside Scrap. Help explains item destruction, rarity rewards, skill bonuses, fragments, iron and the three-use floor limit. Unavailable Scrap, Infuse and Reforge controls open explanations rather than doing nothing.
- The Scrap reward label now includes the Scrapper skill bonus, matching the actual reward. The gameplay formula is unchanged.
- A gold ember counter with its icon is always visible at the top of the gameplay HUD. Hover it to learn about carried versus banked embers. Loot and equipment windows also show carried embers.

Help stays behind explicit clicks or deliberate hover. Closing a help panel does not activate the background menu. Keyboard Enter/Esc and controller confirm/back dismiss it. Help does not consume resources or change the current menu, and it is not a new save-state mode.

Existing profiles and runs remain compatible; no restart is required. Combat, room generation, unlock conditions and resource prices are unchanged.

Validation includes lock/unlock behavior, Daily restrictions, help input isolation, pickup action sizes and navigation, correct Scrap rewards, profile/save restoration, replay systems, treasure flow across 500 floors and text fitting. Native visual checks covered the pickup window, HUD, unlock messages and Scrap explanation.
