# Material icon placeholders

The smithy and tracked goals use the existing pixel-art icon set as temporary material markers. The material name remains beside every marker. Dedicated sprites can replace these without changing save data.

- Ore: iron ingot (placeholder for raw ore)
- Monster parts: attack/sword icon (placeholder for monster parts)
- Warden cores: red relic gem (placeholder for a core)
- Guard alloy: shield (placeholder for a metal alloy)
- Imp essence: ice icon (placeholder for essence)
- Mire gel: poison icon (placeholder for slime gel)

Some legacy messages and other game screens still use text-only material mentions; this list records the current first pass, not a completed audit of every screen.
